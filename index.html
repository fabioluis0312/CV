    Atendente multi-funcional humanizado para WhatsApp

  • Sistema para automatizar o atendimento de clientes on-line via WhatsApp.
    Recebe as mensagens, que passam por um tratamento anti-spam (Rate Limiting) e, após isso, passam por um pré-cadastro automático do número do cliente. Entra em um funil para verificar se o atendente respondeu ou não, para que não haja dupla mensagem ou interferência do sistema.
    Verifica o tipo de mensagem: se for texto, é encaminhada diretamente ao modelo de IA (Inteligência Artificial); se for imagem, é encaminhada para um sistema de mensagem já pronto, informando que não consegue visualizar; se for áudio, é encaminhada para um modelo de IA capaz de interpretar áudio.
    Após a conclusão do sistema de funil, é enviada ao sistema de mensageria (RabbitMQ) para que passe pelo processo de juntar as mensagens e enviá-las ao modelo de IA (Inteligência Artificial).
    O RabbitMQ, ao receber as mensagens do modelo de IA, encaminha-as para um processo de quebra de texto, onde uma mensagem possivelmente extensa é separada em pequenas partes, deixando o cliente mais confortável.
    O atendente multifuncional também consegue realizar a pré-venda, acessando um banco de dados com o estoque de produtos prontos para venda.

  • Impacto: Reduziu o tempo de espera do cliente em aproximadamente 43%, melhorou a satisfação do cliente e aumentou as vendas em cerca de 15% devido à eficiência e personalização do atendimento.
