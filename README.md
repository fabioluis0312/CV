# Currículo — Fábio Brizotti

Currículo profissional em HTML e CSS, desenvolvido com foco em apresentação visual refinada, legibilidade, responsividade e otimização para impressão em formato A4.

Este projeto foi estruturado para funcionar como um portfólio de carreira digital, com layout clean, leitura confortável e visual elegante, além de manter uma organização clara para fácil manutenção e atualização de conteúdo.

## ✨ Visão geral

O objetivo deste projeto é apresentar informações profissionais de forma objetiva, moderna e impactante, preservando uma estética profissional e alinhada ao uso em recrutamento técnico e avaliação de perfil.

O currículo foi pensado para:

- manter um layout visual simétrico e elegante;
- funcionar em diferentes tamanhos de tela;
- manter boa legibilidade em impressão;
- facilitar a edição de dados pessoais, experiências e formação;
- ter uma estrutura simples, performática e facilmente personalizável.

- Layout em formato A4 para impressão profissional;

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone https://github.com/fabioluis0312/CV.git
```

2. Acesse a pasta do projeto:

```bash
cd curriculum
```

3. Abra o arquivo `index.html` no navegador para visualizar o currículo.

4. Para testar a versão para impressão, use o navegador e selecione a opção de imprimir em PDF.

## 🧠 Arquitetura e organização

A estrutura do projeto foi organizada para separar as responsabilidades:

- `index.html`: página principal do currículo;
- `curriculum.html`: versão alternativa ou refinada do documento;
- `css/reset.css`: reset de estilos do navegador;
- `css/default.css`: estilos base e padrões globais;
- `css/style.css`: estilos visuais específicos do layout do currículo.

Essa divisão torna o código mais limpo, facilita manutenção e melhora a escalabilidade do projeto.
